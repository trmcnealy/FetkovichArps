# Fetkovich & Arps Curves in PowerBI

![Fetkovich Arps Curves](https://github.com/trmcnealy/FetkovichArps/blob/main/Assets/Curves.png?raw=true)

You need R, to run the script. You can download R here: https://cran.r-project.org/bin/windows/base/old/4.6.0/R-4.6.0-win.exe

The current dataset is from Enverus; All Permain Basin Well tests since 2015. Change the page "API" filter to select a Well.

At the top of the script change the values of "tDt" and "qDq" to set the Match Point.

To assign new values; rename your fields to "API", "TestDate", "OilVolume_bbl", "WaterVolume_bbl" or edit the script.
